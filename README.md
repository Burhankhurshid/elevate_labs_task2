### Dataset
`superstore_sales_practice.csv` is a generated practice dataset of 240 sales orders across 2025. It is synthetic, not the official Kaggle Superstore dataset.

### Deliverables
- `Task2_Visual_Report.pdf`: visual report with charts, insights and recommendations.
- `superstore_sales_practice.csv`: dataset used.
- `create_visualizations.py`: reproducible Python visualization script.
- Four PNG chart files.
- `insights_summary.txt`: key findings.

### Tools
Python, Pandas and Matplotlib (free tools).

### Reproduce
Install: `pip install pandas matplotlib`
Run: `python create_visualizations.py`

### Findings
- Total sales: 114,590.50
- Total profit: 19,952.94
- Orders: 240
- Highest-sales region: South
- Highest-sales category: Technology
- Highest-sales month number: 12

The line chart shows monthly movement. Bar charts compare regional sales, category sales and category profit. The report distinguishes revenue from profit.

### Limitation
The dataset is synthetic. Findings are for practice only and must not be represented as real company results. Currency is unspecified.
